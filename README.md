# ✈️ Aircraft Space Tracker

Профессиональное консольное приложение на языке Python для мониторинга воздушного пространства выбранных стран в реальном времени. Проект разработан в строгом соответствии с парадигмой объектно-ориентированного программирования (ООП), первыми двумя принципами SOLID (SRP, OCP) и требованиями технического задания.

## 🗂️ Структура проекта

Код распределен по изолированным модулям в соответствии с принципом разделения ответственности (Single Responsibility Principle):

```text
project_folder/
│

│   └── aeroplanes.json    # Плоская база данных текущих воздушных судов
│
├── src/                   # Исходный код бизнес-логики приложения
│   ├── __init__.py
│   ├── api.py             # Абстрактный интерфейс и бесключевой коннектор к API (Nominatim и OpenSky)
│   ├── models.py          # Модель данных самолета с валидацией типов и dunder-методами сравнения
│   └── storage.py         # Абстракция репозитория и JSON-коннектор для CRUD-операций с файлами
│
├── tests/                 # Модули юнит-тестирования системы (библиотека pytest)
│   ├── __init__.py

│   ├── test_storage.py    # Тестирование атомарной записи, обновления и удаления из файлов

│
├── main.py                # Главная точка входа, связывающая компоненты, и консольный интерфейс (CLI)
```

## 🛠️ Описание модулей системы

### 1. [src/api.py](src/api.py) — Интеграция с внешними API
* **`BaseAPIAdapter`**: Абстрактный класс (интерфейс), задающий контракт на получение данных авиации.
* **`FlightAPIAdapter`**: Конкретная реализация. Сначала выполняет скрытый запрос к гео-базе `nominatim.openstreetmap.org` для вычисления границ (`boundingbox`) условного прямоугольника страны, а затем передает координаты в REST API `opensky-network.org` для выгрузки живой матрицы состояний самолетов в небе и на земле. Реализована защита от сетевых сбоев и таймаутов.

### 2. [src/models.py](src/models.py) — Объектная модель воздушного судна
* **`Aeroplane`**: Класс инкапсулирует в себе 5 строго типизированных атрибутов (`icao24`, `callsign`, `origin_country`, `velocity`, `baro_altitude`).
* Внедрен внутренний метод принудительной валидации типов. При передаче со стороны API некорректных значений или `None/null`, они безопасно приводятся к стандартному `0.0`, предотвращая падение программы.
* Переопределены dunder-методы (`__lt__`, `__le__`, `__eq__`) для сравнения самолетов: базовым критерием выступает скорость движения, при равенстве скоростей — барометрическая высота. Добавлены экспресс-методы `is_higher_than()` и `is_faster_than()`.

### 3. [src/storage.py](src/storage.py) — Паттерн «Репозиторий» для хранения данных
* **`BaseStorage`**: Абстрактный класс, декларирующий обязательные CRUD-операции для хранилища.
* **`JSONStorage`**: Конкретный файловый коннектор. Реализует атомарную дозапись новых бортов (с автоматическим обновлением данных, если `icao24` уже существует) и точечную фильтрацию массива при удалении элемента. Логика чтения и записи полностью изолирована от внешнего кода.

### 4. [main.py](main.py) — Консольный интерфейс и оркестрация
* Связывает воедино сетевые запросы, парсинг данных в объекты ООП-моделей и их дисковое сохранение.
* Предоставляет пользователю структурированное текстовое меню, включающее:
  1. Обновление БД по заданной стране.
  2. Вывод **ТОП-N самолетов по высоте** полета в порядке убывания (**DESC**).
  3. Регистронезависимый поиск бортов по стране их регистрации.
  4. Дополнительный функционал: мгновенный поиск и вывод карточки самого быстрого самолета в небе над регионом.
